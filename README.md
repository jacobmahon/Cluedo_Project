To run this file, the directory must be executed from the same directory as main.py within Cluedo_Project_SourceCode.

The only file that needs to be executed in this directory is main.py. In this release, the 4 files used are main.py for most of the program logic and running the main executable, button.py for the button class, characters.py for the character class, weapon_pieces.py for the weapon_pieces class, and the Picture_storage folder, which contains all the images the game uses.

The libraries involved, excluding the classes mentioned above, are pygame, sys, and random. 

The only library not native to default Python is pygame, which requires an external download unless the user already has it. Pygame is a popular library.

A Python interpreter is also needed. A Python interpreter 3.x.x or later should work fine, with 3.10.x or later working best.

This project is 100% in Python, so if you address the above, you should be able to run this game.

The game has 6 players.

Player 1 = Miss_Scarlet = Pink
Player 2 = Colonel_Mustard = Blue
Player 3 = Professor_Plump = Black
Player 4 = Mrs_Peacock = Red
Player 5 = Mr_Green = Orange
Player 6 = Dr_Orchid = Green (The AI Controlled Player)

The upper button says Click to Make a Guess; this is the accusation button.

The button below, Click to Advance the Game, advances the game.

The logic for directions is up, right, down, left.

All interactions with the game require clicking the screen and the text buttons.

After that, the game follows accordingly.

Some prompts might print in the terminal; this helps the user test the logic.
